# Vexora 🎬

Vexora is a video-sharing platform backend built using Node.js, Express.js, MongoDB, and Cloudinary.

## Tech Stack
- Node.js
- Express.js
- MongoDB
- Mongoose
- Cloudinary
- JWT Authentication

## Features
- RESTful API architecture
- User authentication
- Video upload infrastructure
- MongoDB database integration
- Cloudinary media storage

## Project Status
Backend development and deployment in progress.
React frontend planned.
